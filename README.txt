VERSIÓN 4.52 — RETORNO AL MODO CAMPOS

Las solicitudes CON SEGURO y SIN SEGURO utilizan nuevamente las plantillas AcroForm con sus recuadros/campos originales. Los datos se escriben automáticamente mediante setText/checkBox y se actualizan las apariencias del formulario. No se borran widgets ni se dibuja sobre las páginas. Se conservan las funciones actuales de compra de deuda, DXP y DPS.
