# Solicitud de Préstamo por Convenio — v5.21

Paquete para GitHub/GitHub Pages con integración de DXP por convenio.

## Estructura
- `index.html`: aplicación web.
- `DXP/`: plantillas DXP originales proporcionadas para cada convenio.
- `CARTA_PODER_*.pdf`: plantillas de Cartas Poder existentes.
- `VERSION.txt`: versión publicada.

## DXP integrado
- ESSALUD Nuevo/Ampliación
- ESSALUD Compra de Deuda
- Marina de Guerra
- MIDAGRI
- Ministerio Público
- Fuerza Aérea del Perú
- Sub CAFAE SUR
- Convenios General
- RENIEC
- Poder Judicial
- Hospital San Bartolomé
- Ejército del Perú
- PNP

## Nota para GitHub Pages
La carpeta `DXP` debe mantenerse junto al `index.html` porque la aplicación carga las plantillas con rutas relativas.
